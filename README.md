# Movie Recommendation System

A Machine Learning project that recommends similar movies using Content-Based Filtering and Cosine Similarity.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Features
- Movie recommendations
- User-friendly interface
- Fast similarity search

## Run Project

```bash
streamlit run app.py
```

## Dataset
TMDB 5000 Movie Dataset
